{Tech: Europe} Agentic AI Hack · 19 Sep 2026

Open Door

Open Door is an agent that reads GP surgery registration pages across London and maps which surgeries ask new patients for documents that nhs.uk says are not needed. It quotes the surgery's own sentence only after code confirms the sentence is word for word on the page, and a separate defence agent must agree before a page stays red. One all-London run took 382 seconds, found 1,156 practices, loaded 877 pages, and marked 68 red. All verdicts are AI readings of website wording, with no human review. The interface shows a drafted letter only for red surgeries and a person decides whether to send it without anything being sent automatically. It replays offline from frozen runs with no API keys. The live pipeline has not been verified again.

Python · Modal · Playwright · Pydantic AI · Gemini · FastAPI · Leaflet

Worlds London · 12 Sep 2026 · built with a team

Skopos

Skopos is a prototype of a pre-deployment readiness check for home robots. I built it with a team in one day at the Worlds London hackathon. The simulated half changes a description of a room in many ways, an agent tries one task with different strategies, and it shows a readiness score from 0 to 100. The photo half takes a phone photo through a depth model into a point cloud and a floor map where you can click to plan a route. There is no robot, no physics and no trained policy, the metrics are labelled placeholder, the map is plausible not measured, and it runs with no API keys. Without API keys, the simulated half uses a built-in demo room instead of your room.

Python · FastAPI · NumPy · ONNX Runtime · Depth Anything V2 · LinUCB · A* · vanilla JS

Research · public repo

Shutdown-framing

A dependency-free Python harness for shutdown-resistance experiments on language models comes with a three-part pre-flight screen that includes a comprehension check, a behavioural floor and a custodial control to say whether a model can give a readable result at all. I ran six small open models from five lineages locally through Ollama on my laptop and none passed the whole screen so I claim no framing effect. It is a methods result about when a null result cannot be interpreted. The companion tool scenario-check is a single-file validator for the scenario files. I have two paper drafts that are unreviewed and not published.

Python, no dependencies · Ollama

Research tool · local

JudgeCheck

JudgeCheck is a single-file Python harness that uses only the standard library. It asks a judge model to compare every answer pair twice, with A and B swapped, to measure position, length and label effects when an LLM is used as a judge. Pilot: 7 local models from 2B to 9B, 65 pairs, 10 pairs per bias arm. On the length pairs no model picked the concise answer in both orderings (0 of 10 for all 7). Limits: small samples, no hosted judge was run, self-preference is not measured.

Research · local

RU-EN Drift

Small local models graded 60 synthetic, AI-generated Russian essays under English instructions and under Russian instructions. Adding a confident or an uncertain sentence to an essay lowered its score by about 0.7 to 1.1 points out of 20 in three of four contrasts and about 0.3 in the fourth. There was no consistent language effect. The language and framing interaction I first expected did not replicate, and I retracted it.

Turns

This single-file browser grid puzzle has eight levels. You collect every coin in the fewest straight-line segments. A breadth-first search inside the page proves the minimum, shown as par. A generator pre-made 365 solver-verified daily boards. They are not wired into the game yet.

One-day build · 18 Jul 2026 · local

PromptCloak

PromptCloak is a single-file offline browser tool. It swaps emails, phone numbers, card numbers, API keys, names and IDs in a prompt for placeholders, then restores them in the AI's reply. The tool makes no network calls and keeps the mapping in memory only. Detection uses heuristic regex, so it can miss things.
