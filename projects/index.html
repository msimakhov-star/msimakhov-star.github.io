{Tech: Europe} Agentic AI Hack · 19 Sep 2026 · built solo

Open Door

Open Door is an agent that reads GP surgery registration pages across London and maps which surgeries ask new patients for documents that nhs.uk says are not needed. It quotes the surgery's own sentence only after code confirms the sentence is word for word on the page, and a separate defence agent must agree before a page stays red. One all-London run took 382 seconds, found 1,156 practices, loaded 877 pages, and marked 68 red. All verdicts are AI readings of website wording, with no human review. The interface shows a drafted letter only for red surgeries and a person decides whether to send it without anything being sent automatically. It replays offline from frozen runs with no API keys. The live pipeline has not been verified again. On 28 September 2026 the organisers wrote that Open Door took first place in the Pydantic side challenge.

GPT-6 Astra Hackathon, London · 6 Oct 2026

Photo-to-Physics

A student photographs a physics problem or describes an experiment in words. GPT-6 Astra reads it and writes a live interactive experiment that runs in the browser, inside a sandboxed frame. The app checks the experiment against the textbook formula with deterministic code. If they disagree, the model gets the measured error back and fixes its simulation, for up to three rounds. I built this in one day with GPT-6 Astra, Codex and Lovable. It only covers three topics: projectile motion, simple pendulum, and a block on an incline.

Cambridge x Arcade AI Hackathon · 3 to 4 Oct 2026

Nyx

Nyx is a physics sandbox game for ages 7 to 17. Players learn about Gravity and Time by attending classes with Professor Ada. You predict outcomes, run experiments, and pass a three-question check to unlock powers. I used the GAME RULE label to distinguish real physics from game mechanics. Every script and asset was generated by Arcade's Morph agents from my prompts.

Hack-Nation x RealPage · online · 4 Oct 2026

Rental Housing Law Navigator

A user types an address and a date to see which rental housing rules apply. The system covers 3 US states, 10 cities, and 6 rule categories. Each rule check ends as yes, no or unknown, with the source sentence quoted word for word and a plain explanation in English and Spanish. Results for 500 sample addresses were generated as of 1 October 2026. 30.9 percent of results are unknown. No human or lawyer reviewed the tool, and the rule extraction was run by Claude Code agents. This is not legal advice.

Worlds London · 12 Sep 2026 · built with a team

Skopos

Skopos is a prototype of a pre-deployment readiness check for home robots. I built it with a team in one day at the Worlds London hackathon. The simulated half changes a description of a room in many ways, an agent tries one task with different strategies, and it shows a readiness score from 0 to 100. The photo half takes a phone photo through a depth model into a point cloud and a floor map where you can click to plan a route. There is no robot, no physics and no trained policy, the metrics are labelled placeholder, the map is plausible not measured, and it runs with no API keys. Without API keys, the simulated half uses a built-in demo room instead of your room.

One-day prototype · 24 Aug 2026 · local

Turns

This single-file browser grid puzzle has eight levels. You collect every coin in the fewest straight-line segments. A breadth-first search inside the page proves the minimum, shown as par. A generator pre-made 365 solver-verified daily boards. They are not wired into the game yet.

One-day build · 18 Jul 2026 · local

PromptCloak

PromptCloak is a single-file offline browser tool. It swaps emails, phone numbers, card numbers, API keys, names and IDs in a prompt for placeholders, then restores them in the AI's reply. The tool makes no network calls and keeps the mapping in memory only. Detection uses heuristic regex, so it can miss things.
